# Energy Systems

Exploring global power plant data using DuckDB, spatial SQL and H3.

* Query and analyse the Global Power Plant Database
* Create and query spatial point geometries with DuckDB Spatial
* Analyse power plants around Kraków
* Aggregate energy capacity using H3 hexagonal grids
* Export spatial results to GeoJSON and Parquet
* Visualise global energy data in 3D with PyDeck

Tools: Python, DuckDB, Spatial SQL, H3, GeoJSON, Parquet, PyDeck
