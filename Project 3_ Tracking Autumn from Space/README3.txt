# Tracking Autumn from Space

Using Sentinel 2 satellite imagery to analyse vegetation in the Tatra Mountains.

* Search satellite imagery through the Microsoft Planetary Computer STAC API
* Filter imagery by location, date and cloud cover
* Process Sentinel-2 red and near-infrared bands
* Calculate NDVI
* Crop and visualise the resulting raster
* Export the result as a GeoTIFF

Tools: Python, STAC, Sentinel-2, rioxarray, xarray, NumPy, Matplotlib
